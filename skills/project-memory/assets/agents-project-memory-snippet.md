## 项目记忆

- 开始实质性工作前，先读取 `docs/project-memory/PROJECT_STATE.md`。
- 需要历史背景时，先读取 `docs/project-memory/SESSION_INDEX.md`，再按需打开相关会话记录；默认不要加载全部历史。
- 将 `PROJECT_STATE.md` 视为当前状态的权威快照，将会话文件视为仅追加的历史记录。
- 仅在用户明确调用 `$project-memory` 时更新项目记忆；不要把 `AGENTS.md` 变成开发日志。
- 项目记忆文档默认使用简体中文，但代码标识符、路径、命令和原始错误信息保持原样。
- 不得在项目记忆文件中记录密码、令牌、私钥、Cookie 或授权请求头。
